##### Iniciamos con laravel 12.28.1 y php 8.4.5
composer create-project laravel/laravel gestorDeJardines

##### Instalé livewire 3.6:
composer require livewire/livewire

##### Instalé mailgun y http-client v. 7.3
composer require symfony/mailgun-mailer symfony/http-client

##### Generé liga para subir archivos a public (php artisan  storage:link)
### en la carpeta /storage/app/ hacer una liga simbólica denominada private que redirige a public/
ln -s public/ storage/app/private

##### Instalé laravel sanctum y api route (para api rest)
php artisan install:api

##### Instalé Laravel jwt para autenticar API
composer require tymon/jwt-auth

##### Instalé maatwebsite/excel (para abrir archivos xls)
composer require maatwebsite/excel
